# zhiyangxep-notes

Platform engineer · Scala and Akka · learning in public

给自己省点事的小工具

## 用法

```bash
cat data.txt | cargo run
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 安装

```bash
git clone https://github.com/USER/zhiyangxep-notes.git
cd zhiyangxep-notes
cargo build --release
```

## 为什么写

现有的工具都太重，就想要个能管道拼接的小东西。
